# Airline Database Sorting Program ✈️

## Overview  
This Python script uses **SQLite** to manage flight data, allowing users to sort flights based on available seats and departure time.

## Features  
✅ Stores flight details in an **SQLite database**  
✅ Sorts flights by **available seats** (ascending or descending)  
✅ Sorts flights by **departure time** (earliest to latest or vice versa)  
✅ Uses **Python’s SQLite module** for database operations  

## Technologies Used  
- Python 🐍  
- SQLite 🗄️  
- Datetime module ⏳  

## Installation & Usage  
```bash
# Clone the repository
git clone https://github.com/your-username/airline-db-sorting.git

# Navigate to the project directory
cd airline-db-sorting

# Install SQLite if not already installed
pip install sqlite3

# Run the script
python main.py
```
